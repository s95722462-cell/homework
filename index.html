지난 숙제

탭을 닫아 두면 알림이 오나요?

솔직히 말하면 이 화면(탭)이 열려 있을 때만 21:00에 알려 드릴 수 있어요. 탭이나 앱을 닫으면 웹 페이지는 시간을 알 수 없어요. 대신 휴대폰·PC가 대신 불러 주게 해 두세요.

아이폰 — 단축어 앱으로 매일 열기

  1. 단축어 앱 → 아래 자동화 → + → 특정 시간
  2. 시간 21:00, 매일, 즉시 실행 고르고 다음
  3. 동작 URL 열기 → 이 주소 붙여 넣기 → 완료

안드로이드 — 이 화면을 홈 화면에 추가(메뉴 ⋮ → 홈 화면에 추가)하고, 시계 앱에 21:00 알람 "숙제"를 만들어 두세요. 알람이 울리면 숙제 아이콘을 누르면 돼요.

PC (Edge) — 주소창 오른쪽 앱 설치로 숙제를 설치한 뒤 edge://apps → 숙제 → 디바이스 로그인 시 자동 시작을 켜 두면 PC를 켤 때마다 숙제가 함께 열려요.

놓친 날은 다음에 열 때 "어제 숙제"로 한 번 물어봐요.
